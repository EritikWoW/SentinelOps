# SentinelOps icon generation prompts

The metric icon assets currently used by the dashboard were cropped directly
from the approved SentinelOps Command Center reference image:

- `src/web/assets/metric-active.png`
- `src/web/assets/metric-workflow.png`
- `src/web/assets/metric-safety.png`
- `src/web/assets/brand-lockup.png`

The following icons are not present as clean, reusable standalone assets in the
reference. If we later generate them, keep the same visual language and do not
replace the four extracted reference assets.

## Form service icon

Create a single small product UI icon for a service/container cube, front-facing
isometric outline, cyan-blue neon stroke, dark navy interior, subtle glow,
rounded geometric corners, no text, no letters, no shadow outside the icon,
designed to sit inside a 24px dark dashboard control. Match the SentinelOps
Command Center reference: dark cloud-control-plane UI, precise technical line
work, restrained cyan and blue palette, transparent background if supported.

## Severity warning icon

Create a single small product UI icon for a high-severity incident: compact
shield outline with a centered exclamation mark, red-coral neon stroke, dark
navy interior, subtle glow, rounded geometric corners, no text, designed to sit
inside a 24px dashboard select control. Match the SentinelOps Command Center
reference style and maintain strong legibility at small size.

## Action and document icons

Create a matching pair of small dashboard utility icons: one minimal cyan plus
symbol for adding an incident and one outlined document/file icon for loading a
demo scenario. Use the same dark navy, cyan-blue neon stroke, rounded corners,
technical line weight, no text, and consistent 24px UI scale.

## Settings and safety icons

Create a matching pair of small dashboard utility icons: one restrained blue
gear for settings and one cyan shield with a checkmark for the safety policy.
Use the same SentinelOps Command Center line-art system, dark navy interior,
subtle cyan glow, no text, no gradients inside the icon, and clear recognition
at 20-24px.
